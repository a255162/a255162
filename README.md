# 寶可夢卡牌鑑定

手機用的寶可夢卡牌鑑定 App。純前端 PWA：拍照與影像分析全在手機上跑，
不需要伺服器、不上傳照片、可離線使用。

**線上版：https://a255162.github.io/a255162/**
手機開啟後從瀏覽器選單「加到主畫面」，即可像一般 App 使用，離線也能跑。

## 功能

**辨識查價（主要功能）**
- 用卡名（繁中／日文／英文）或卡號查卡，或選系列＋卡號
- 顯示官方卡圖、系列、卡號、稀有度、插畫師
- 參考行情：cardmarket（歐元）與 tcgplayer（美元），自動換算台幣
- 一鍵開啟蝦皮／露天／Yahoo 拍賣／駿河屋搜尋，看台日實際成交價

**量置中（附加）**
- 拍照 → 四角透視校正 → 量出黃框上下左右寬度與置中比例

## 本機執行

```
python serve.py
```

會印出手機可以連的區網網址（手機需連同一個 Wi-Fi）。
電腦上開 http://localhost:8080 即可測試。

## 能力邊界

**價格**
- 價格來源是 cardmarket（歐洲）與 tcgplayer（美國），是**歐美市場**的行情。
  中文卡與日文卡查到的價，是對應歐美版商品的價格，跟台灣行情常常差很多。
- **中文卡約有一半查不到價**。SP、SK、SVAW 這類中文限定系列在歐美沒有對應商品，
  換語言也救不回來。這種情況程式會直接說查不到，並把台／日搜尋連結放到最上面。
- 同一張卡不同市場的價差可能到好幾倍，所以主打價顯示的是**區間**而不是單一數字。

**置中量測**
- 量的是幾何距離，對合成測試卡的誤差在 ±1.2 個百分點以內。
- 全圖卡、無框卡沒有一致的外框可量，程式會顯示「無法可靠量測」而不給分數。
- 這是送評前的自我檢查，不等於 PSA／BGS 的官方分數。

## 專案結構

```
index.html          單頁殼，五個分頁
css/style.css       手機優先的深色介面
js/tcgdex.js        TCGdex API 封裝、價格整理、匯率換算
js/identify.js      辨識查價分頁
js/db.js            IndexedDB 快取（離線也查得到查過的卡）
js/imageutil.js     載圖、四角偵測、透視校正（置中量測的基礎）
js/capture.js       拍照輸入與四角框選 UI（含放大鏡）
js/grade.js         品相量測（M1：置中）
js/overlay.js       把量測結果畫回卡片圖上
js/app.js           分頁切換與流程串接
sw.js               離線快取
tools/make_icons.py       產生 PWA 圖示
tools/make_test_card.py   產生已知答案的合成測試卡
serve.py            本機測試伺服器（不會部署出去）
```

## 測試

`tools/make_test_card.py` 會產生一組**已知置中偏移量**的合成卡片圖
（正拍、斜拍、旋轉、過曝、過暗、拍很小、全圖卡），用來驗證量測準度與重複性。
真值寫在該檔案的說明裡。

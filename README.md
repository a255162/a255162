# 寶可夢卡牌鑑定

手機用的寶可夢卡牌鑑定 App。純前端 PWA：拍照與影像分析全在手機上跑，
不需要伺服器、不上傳照片、可離線使用。

## 目前進度

| 里程碑 | 內容 | 狀態 |
| --- | --- | --- |
| M1 | 拍照、四角透視校正、置中量測 | ✅ 完成 |
| M2 | 邊角／邊緣／表面分析、綜合分數 | 未開始 |
| M3 | 卡片辨識與查價（繁中／日文／英文） | 未開始 |
| M4 | 收藏管理與匯出 | 未開始 |
| M5 | 真偽輔助檢查 | 未開始 |

## 本機執行

```
python serve.py
```

會印出手機可以連的區網網址（手機需連同一個 Wi-Fi）。
電腦上開 http://localhost:8080 即可測試。

## 能力邊界

- **置中量測**量的是幾何距離，是這個 App 裡唯一能量得準的項目。
  對合成測試卡的誤差在 ±1.2 個百分點以內。
- 全圖卡、無框卡沒有一致的外框可量，程式會直接顯示「無法可靠量測」而不給分數。
- 這是**送評前的自我檢查**，不等於 PSA／BGS 的官方分數——官方還會看邊角、
  邊緣、表面與印刷瑕疵，而且由人眼判定。

## 專案結構

```
index.html          單頁殼，五個分頁
css/style.css       手機優先的深色介面
js/imageutil.js     載圖、四角偵測、透視校正（所有分析的基礎）
js/capture.js       拍照輸入與四角框選 UI（含放大鏡）
js/grade.js         品相量測（M1：置中）
js/overlay.js       把量測結果畫回卡片圖上
js/app.js           分頁切換與流程串接
sw.js               離線快取
tools/make_icons.py       產生 PWA 圖示
tools/make_test_card.py   產生已知答案的合成測試卡
serve.py            本機測試伺服器（不會部署出去）
```

## 測試

`tools/make_test_card.py` 會產生一組**已知置中偏移量**的合成卡片圖
（正拍、斜拍、旋轉、過曝、過暗、拍很小、全圖卡），用來驗證量測準度與重複性。
真值寫在該檔案的說明裡。
